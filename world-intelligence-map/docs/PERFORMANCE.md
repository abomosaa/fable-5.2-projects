# Performance measurements

_Generated by `npm run bench` – numbers are from the machine below and will differ elsewhere._

- Date: 2026-11-10 · Node v26.13.0 · Intel(R) Core(TM) i7-14700K (28 threads) · linux x64
- Database: in-memory SQLite (node:sqlite 3.54.0) with R*Tree spatial index and FTS5
- Data set: all 40 adapters on their bundled fixtures plus 50,000 generated VIIRS detections parsed by the real FIRMS adapter

| Idempotent re-ingestion of the same data | 3,281 ms, 0 records changed |
