# Big Shoulders

`BigShoulders-latin-variable.woff2` is the Latin subset of the variable font
(weight 100–900, optical size 10–72) from Google Fonts, licensed under the
SIL Open Font License 1.1 — https://fonts.google.com/specimen/Big+Shoulders

It is self-hosted through `next/font/local` because `next/font/google` has no
fallback metrics for this family and logs a warning on every build.
